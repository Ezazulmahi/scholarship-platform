This is a frontend-only [Next.js](https://nextjs.org) scholarship platform concept.

## Getting Started

Run the development server from the `frontend/` directory:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the design.

The main homepage UI lives in `app/home-client.tsx`, with `app/page.tsx` rendering that layout.

## Notes

- There is no backend app in this version of the project.
- No API environment variables are needed.
- The layout is ready for future data integration if you decide to add one later.
